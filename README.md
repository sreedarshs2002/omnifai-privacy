# Omnifai Privacy Policy

This repository hosts the Privacy Policy webpage for the **Omnifai Instagram Automation POC**.

## About the Application

Omnifai Instagram Automation POC is an internal proof-of-concept application developed to demonstrate automated responses to Instagram Direct Messages using Meta APIs.
