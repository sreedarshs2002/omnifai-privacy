Omnifai Instagram Automation POC - Privacy Policy

Last updated: November 24, 2026

1. Purpose

Omnifai Instagram Automation POC is an internal proof-of-concept application developed to demonstrate automated responses to Instagram direct messages using Meta APIs.

2. Information Processed

The application may process:

  • Instagram sender account ID.
  • Instagram direct message text.
  • Message event information provided by Meta.

3. How Information Is Used

Information is used to receive Instagram webhook events, process incoming messages and test automated responses.

4. Data Storage and Security

Message details may appear in development application logs. Access tokens are maintained securely through environment variables and must not be shared publicly.

5. Sharing of Information

Information is processed through Meta's Instagram APIs and the Omnifai development environment. Personal information is not sold to advertisers.

6. Data Retention and Deletion

Information is retained only as necessary for development, testing and troubleshooting. Users may contact Omnifai to request deletion of information associated with their test interactions.
